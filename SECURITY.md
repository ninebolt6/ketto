# Security Policy

## Supported Versions

Only the latest release is supported with security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](../../security/advisories/new)
instead of opening a public issue. Include steps to reproduce and the affected
version. You'll get an acknowledgement as soon as possible; if the report is
accepted, a fix will be released before the issue is disclosed publicly.
