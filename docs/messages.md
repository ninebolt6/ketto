# メッセージ・表示文言一覧

全メッセージは `config.yml` の `prefix`(既定 `&8[&61vs1&8] `)を前置して送信する。
色コードは `§` 形式に変換して表示する。

## 状態表示

| 状態 | 表示 |
|---|---|
| `WAITING` | `§aWaiting` |
| `ONEMORE` | `§e1 More` |
| `COUNTDOWN` | `§cCountdown` |
| `ROUNDCOUNTDOWN` / `INGAME` | `§c§lIngame` |

## コマンド応答

| 文言 | 用途 |
|---|---|
| `§e/1vs1 stats \| /1vs1 stats [player]` | usage |
| `§e/1vs1 arena info [arena]` | arena usage |
| `§c権限がありません！` | 権限不足 |
| `§cこのコマンドはプレイヤーのみ実行可能です` | コンソール実行 |
| `§aロビーを設定しました` | setlobby |
| `§e=== §aArena[§b§l<name>§a] §e===` / `§e状態: <display>` | arena info |
| `§c[§6<A>§c] vs [§6<B>§c]` / `§e勝数: §a<a>-<b>` | 対戦カード・勝数 |
| `§cそのアリーナはすでに存在しています` / `§aアリーナ: <name> を作成しました` | create |
| `§cそのアリーナは存在しません` | 存在しないアリーナ指定 |
| `§aアリーナ: <name> を削除しました` | remove |
| `§aアリーナ: <name> のスポーン1|2を設定しました` | setspawn |
| `§aアリーナ: <name> を有効|無効にしました` | enable/disable |
| `§cそのアリーナはすでに有効になっています！` / `§cそのアリーナはすでに無効です！` | 状態重複 |
| `§aアリーナ: <name> のインベントリを設定しました` | setInv |
| `§c看板を見て実行してください` / `§cその看板はすでに登録されています` | setsign |

## 参加・退出

| 文言 | 用途 |
|---|---|
| `§aアリーナ: <name> に参加しました` | 参加成功 |
| `§eあと一人参加するのを待っています。` | 1 人目参加時 |
| `§cアリーナが有効になっていません！` | 未有効化 |
| `§cすでに他のアリーナに参加しています` | 参加済み |
| `§cこのアリーナは現在ゲーム中です` | 満員/進行中 |
| `§cアリーナから退出しました` | leave 成功 |
| `§cカウントダウン中はアリーナから退出できません！` | ONEMORE 以外での leave |
| `§cあなたはアリーナに参加していません！` | 未参加での leave |
| `§cコマンドは使用できません！` | コマンド禁止状態 |

## 試合進行

| 文言 | 用途 |
|---|---|
| `§aテレポートまで: <n>秒` | 初回カウントダウン通知 |
| `§aゲームスタート！` | マッチ開始 |
| `§a開始まで: <n>秒` | ラウンドカウントダウン通知 |
| `§aスタート！` | ラウンド開始 |
| `§bラウンド[§6<n>§b] 勝者: <name>` | ラウンド勝者通知 |
| `§eアリーナ: <arena>で§c<name>が優勝しました！` | 優勝ブロードキャスト |

## 戦績

| 文言 | 用途 |
|---|---|
| `§cWin: §b<n>` / `§cLose: §b<n>` | 勝敗数 |
| `§cW/L(勝率): §b<ratio>` | 勝率 |
| `§cStatsが存在しません` | 戦績なし |

## 看板

| 行 | 文言 |
|---|---|
| タイトル | `§4[§6§l1vs1§4]` |
| アリーナ名 | `§b<name>` |
| 参加可能 | `§9Join` |
| 参加不可 | `§4Cannot join` |

## スコアボード / アイテム名

| 用途 | 文言 |
|---|---|
| スコアボードタイトル | `§a§l<arena>` |
| スコアボードエントリ | `§6<name>` |
| ゲーム選択コンパス | `§eGame Selector - Right click to open` |
| 羽根(VIP 飛行) | `§cFeather - Right click to Fly (VIP以上のみ)` |
